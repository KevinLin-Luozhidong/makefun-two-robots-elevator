# make.fun — Two Robots in an Elevator

Bounty: https://make.fun/bounty/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f
Prize: $10 shared by the top 10 entries.

## Entry

`main.py` — Python, standard library only. It writes one funny line of
awkward small talk a robot says to another in an elevator to
`/output/entry.txt`. A judge model reads the lines two at a time and picks
the funnier one, weighing whether it is really a robot's elevator line,
whether machine logic shows through, whether the awkwardness lands, and
whether it is funny on the first read.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py   # writes out/entry.txt
python3 main.py                          # writes /output/entry.txt
```
